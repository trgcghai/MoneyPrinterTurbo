## Tính năng 🎯

### Quy trình sáng tạo

- [x] Sử dụng **AI Agent, WebUI, API hoặc CLI** để tạo nhanh hoặc tự động hóa sản xuất video
- [x] Tự động đi từ chủ đề tới kịch bản, lồng tiếng, tư liệu, phụ đề, nhạc nền và dựng video, đồng thời vẫn cho phép kiểm soát từng giai đoạn
- [x] Tạo nhiều biến thể đầu ra theo lô, xem lịch sử tác vụ, nhập hoặc xuất cài đặt tạo video và API key

### Kịch bản và nhà cung cấp mô hình

- [x] Tạo hoặc viết lại **kịch bản video đa ngôn ngữ** bằng AI, hoặc dùng kịch bản tùy chỉnh hoàn chỉnh
- [x] Hỗ trợ các nhà cung cấp hàng đầu như [Kimi / Moonshot AI](https://platform.kimi.ai?track_id=track-f6b0a640d35c41deb03b247242a1058c&aff=moneyprinterturbo), [OpenAI](https://platform.openai.com/api-keys), [Anthropic Claude](https://platform.claude.com/settings/keys), [Google Gemini](https://aistudio.google.com/app/apikey), [DeepSeek](https://platform.deepseek.com/api_keys), [Alibaba Cloud Qwen](https://qwen.ai/apiplatform), [Microsoft Azure OpenAI](https://portal.azure.com/#view/Microsoft_Azure_ProjectOxford/CognitiveServicesHub/~/OpenAI), [ByteDance VolcEngine Ark](https://console.volcengine.com/ark), [xAI Grok](https://console.x.ai/), [MiniMax](https://platform.minimax.io/) và [Xiaomi MiMo](https://platform.xiaomimimo.com/docs/zh-CN/quick-start/first-api-call)
- [x] Kết nối qua [Shengsuan Cloud](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK), [APIMart](https://go.apimart.ai/gh-moneyprinterturbo), [Cloudflare AI Gateway](https://dash.cloudflare.com/), [Alibaba ModelScope](https://modelscope.cn/docs/model-service/API-Inference/intro), [AIHubMix](https://aihubmix.com/), [AIML API](https://aimlapi.com/app/keys), [EvoLink](https://evolink.ai/dashboard/keys), [OpenRouter](https://openrouter.ai/settings/keys), [Ollama](https://ollama.com/), [OneAPI](https://github.com/songquanpeng/one-api), [LiteLLM](https://docs.litellm.ai/docs/providers), [Groq](https://console.groq.com/keys), [Pollinations AI](https://enter.pollinations.ai/) và các gateway hoặc runtime cục bộ tương thích khác

### Tư liệu video và hình ảnh

- [x] Tải lên **ảnh và video cục bộ** của bạn, hoặc lấy stock footage HD từ [Pexels (miễn phí)](https://www.pexels.com/api/), [Pixabay (miễn phí)](https://pixabay.com/api/docs/) và [Coverr](https://coverr.co/developers?ctx=header_navigation)
- [x] Tạo tư liệu nguồn `768P` hoặc `2K` bằng [Metaso MiniMax H3](https://metaso.cn/minimax-h3/?s=MPT), với clip 4-15 giây ở tỉ lệ `9:16`, `16:9` hoặc `1:1`
- [x] Tạo nhiều clip video AI bằng [Shengsuan Cloud AI Video](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK), rồi kết hợp với quy trình lồng tiếng, phụ đề và dựng video của dự án
- [x] Dùng tích hợp gốc [Volcano Engine Ark Seedance](https://console.volcengine.com/ark/region:ark+cn-beijing/apikey) để tạo hình ảnh nhất quán từ từng đoạn kịch bản
- [x] Biến từ khóa kịch bản thành tư liệu video gốc với [WaveSpeed AI](https://wavespeed.ai)
- [x] Truy cập Seedance, Wan và các mô hình text-to-video khác qua [OFox](https://ofox.ai) bằng một API key
- [x] Kết nối dịch vụ [text-to-image tương thích OpenAI](https://platform.openai.com/docs/guides/image-generation) hoặc gateway ảnh tùy chỉnh, rồi chuyển ảnh sinh ra thành clip video động
- [x] Điều chỉnh thời lượng clip, cách fit khung hình và thứ tự tư liệu để phù hợp tỉ lệ khung hình và phong cách kể chuyện

### Lồng tiếng, phụ đề và nhạc nền

- [x] Chọn lồng tiếng tự động, âm thanh tải lên hoặc không lồng tiếng, kèm nghe thử giọng và xem trước toàn bộ lời đọc
- [x] Hỗ trợ **Edge TTS (miễn phí, không cần API key)**, Azure Speech, SiliconFlow, Google Gemini, Xiaomi MiMo, MiniMax, ElevenLabs, Chatterbox, Fish Audio và các dịch vụ giọng nói khác
- [x] Tạo phụ đề và cấu hình font, vị trí, màu, cỡ chữ, viền và kiểu nền
- [x] Dùng nhạc nền ngẫu nhiên, cục bộ hoặc do AI tạo, với điều khiển âm lượng riêng

### Xuất bản và phát hành

- [x] Xuất video dọc `9:16 (1080×1920)`, ngang `16:9 (1920×1080)` hoặc vuông `1:1 (1080×1080)`
- [x] Đăng video hoàn tất trực tiếp lên **TikTok, Instagram và YouTube Shorts**

## Yêu cầu hệ thống 📦

- Nền tảng khuyến nghị: Windows 10+, macOS 11+ hoặc bản phân phối Linux phổ biến
- Triển khai cục bộ cần Python 3.11 trở lên; khuyến nghị Python 3.11
- Không bắt buộc GPU, nhưng GPU giúp phiên âm cục bộ, xử lý video và tạo theo lô nhanh hơn

| Hạng mục | Tối thiểu     | Khuyến nghị | Tối ưu    |
| -------- | ------------- | ----------- | --------- |
| CPU      | 4 nhân        | 6 đến 8 nhân | 8+ nhân   |
| RAM      | 4 GB          | 8 GB        | 16+ GB    |
| GPU      | Không bắt buộc | 4+ GB VRAM  | 8+ GB VRAM |

- Nếu chủ yếu dùng LLM, TTS và nguồn tư liệu online trên cloud, CPU và RAM quan trọng hơn GPU
- Nếu dùng `faster-whisper`, tạo theo lô hoặc xử lý cục bộ nặng, GPU sẽ cải thiện thông lượng rõ rệt

## Cài đặt và triển khai 📥

### Điều kiện tiên quyết

- Triển khai cục bộ cần Python 3.11 trở lên
- Trên Windows, tránh đặt dự án trong đường dẫn có ký tự ngoài ASCII, ký tự đặc biệt hoặc dấu cách

#### ① Clone dự án

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
```

#### ② Hoàn tất thiết lập ban đầu

Ở lần khởi chạy đầu tiên, dự án tạo `config.toml` từ `config.example.toml`, nên bạn không cần tạo tệp này thủ công. Trước khi dùng LLM cloud, nguồn tư liệu online hoặc dịch vụ tạo video AI, hãy thêm API key tương ứng trong phần cài đặt cơ bản của WebUI.

### Triển khai bằng Docker 🐳

#### ① Khởi chạy container Docker

Nếu chưa cài Docker, hãy [tải và cài Docker Desktop](https://www.docker.com/products/docker-desktop/) trước. Nếu dùng Windows, xem tài liệu của Microsoft:

1. [Cài WSL](https://learn.microsoft.com/en-us/windows/wsl/install)
2. [Dùng Docker container với WSL](https://learn.microsoft.com/en-us/windows/wsl/tutorials/wsl-containers)

```shell
cd MoneyPrinterTurbo
docker compose -f docker-compose.release.yml up
```

> Mặc định khuyến nghị là `docker-compose.release.yml`, dùng image dựng sẵn từ GitHub Container Registry: `ghcr.io/harry0703/moneyprinterturbo:latest`.
> Nếu cần tự build image cục bộ, bạn vẫn có thể chạy `docker compose up`.
> Trước lần chạy đầu tiên, sao chép `config.example.toml` thành `config.toml` để mount vào container.

#### ② Truy cập WebUI

Mở trình duyệt và truy cập http://127.0.0.1:8501

#### ③ Truy cập tài liệu API

Mở trình duyệt và truy cập http://127.0.0.1:8080/docs hoặc http://127.0.0.1:8080/redoc

> API mặc định chỉ cho truy cập trình duyệt cùng origin. Chỉ đặt biến môi trường `CORS_ALLOWED_ORIGINS` khi frontend trình duyệt riêng cần gọi API từ origin khác, ví dụ `http://localhost:3000,https://frontend.example.com`. CORS không ảnh hưởng tới curl, Postman, n8n hoặc client phía server.

### Triển khai thủ công 📦

#### ① Tạo môi trường ảo Python

Dùng [uv](https://docs.astral.sh/uv/) để quản lý môi trường Python và dependency. Dự án hỗ trợ Python 3.11 trở lên; ví dụ bên dưới dùng Python 3.11.

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen
```

Nếu chưa dùng `uv`, bạn vẫn có thể dùng `venv + pip`.

```shell
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Ghi chú:

- `pyproject.toml` hiện là manifest dependency chính.
- `uv.lock` cố định môi trường đã resolve, nên mặc định khuyến nghị `uv sync --frozen`.
- `requirements.txt` chỉ giữ lại cho cài đặt legacy bằng `pip`.

#### ② Khởi chạy WebUI 🌐

Chạy các lệnh sau trong `thư mục gốc` của dự án MoneyPrinterTurbo.

###### Windows

```powershell
.\webui.bat
```

Bạn cũng có thể chạy `webui.bat` trong CMD.
`webui.bat` ưu tiên `.venv` của dự án hoặc Python đi kèm gói portable. Nếu không tìm thấy Python của dự án nhưng có `uv`, script tự fallback sang `uv run streamlit`.
Để thiết bị khác trong LAN truy cập WebUI, chạy `set MPT_WEBUI_HOST=0.0.0.0` trước khi chạy `webui.bat`.

###### macOS hoặc Linux

```shell
sh webui.sh
```

Script tự dùng môi trường ảo của dự án hoặc `uv`, đồng thời chọn một cổng cục bộ còn trống. Để thiết bị khác trong LAN truy cập:

```shell
MPT_WEBUI_HOST=0.0.0.0 sh webui.sh
```

Sau khi khởi chạy, trình duyệt sẽ tự mở.

#### ③ Khởi chạy API Service 🚀

```shell
uv run python main.py
```

Nếu đã kích hoạt môi trường ảo thủ công, bạn vẫn có thể chạy:

```shell
python main.py
```

#### ④ Chế độ CLI thuần túy, không cần trình duyệt ⌨️

Nếu không dùng được trình duyệt hoặc port forwarding, hãy tạo video trực tiếp từ dòng lệnh. Lệnh tạo video hoàn chỉnh đơn giản nhất là:

```shell
uv run python cli.py --video-subject "How AI is changing everyday life"
```

Tùy chọn kiểu phụ đề và lồng tiếng được resolve theo thứ tự: **tùy chọn CLI rõ ràng > giá trị `[ui]` đã lưu trong `config.toml` > mặc định tích hợp**. Các cài đặt tạo video khác như nhạc nền, số lượng video và số đoạn văn không được kế thừa từ WebUI. Nếu WebUI đang đặt dùng âm thanh tải lên, hãy truyền rõ `--custom-audio-file` vì đường dẫn đã tải lên không được lưu bền vững.

Để xem đầy đủ tham chiếu lệnh, mô tả tham số và hướng dẫn sử dụng, chạy:

```shell
uv run python cli.py --help
```

Để chạy nhiều tác vụ tuần tự, truyền manifest UTF-8 dạng JSON array hoặc JSONL. Tùy chọn CLI đóng vai trò mặc định, mỗi object ghi đè các trường trong `VideoParams`:

```json
[
  { "video_subject": "How solar panels work" },
  { "video_subject": "How wind turbines work", "video_aspect": "16:9" }
]
```

```shell
uv run python cli.py --batch-file ./tasks.json --stop-at video
```

Manifest được resolve từ thư mục làm việc hiện tại. Các giá trị `custom_audio_file` và `video_materials[].url` cục bộ tương đối bên trong manifest được resolve từ thư mục chứa manifest; đường dẫn truyền qua tùy chọn CLI vẫn theo thư mục làm việc hiện tại. Manifest giới hạn 100 tác vụ và 1 MiB. Tất cả entry được validate trước khi tác vụ đầu tiên bắt đầu; các tác vụ vẫn tiếp tục sau lỗi runtime riêng lẻ; lệnh in một JSON summary khi hoàn tất. Summary chứa `total`, `succeeded`, `failed` và `tasks`; mỗi task entry có `index`, `task_id`, `status`, `result`, `failed_stage` và `error`.

## Lồng tiếng, phụ đề và nhạc nền 🎙️

### Tổng hợp giọng nói

**Azure TTS V1** trong WebUI dùng **Edge TTS** và miễn phí, không cần API key. MoneyPrinterTurbo cũng hỗ trợ **Azure TTS V2**, **SiliconFlow TTS**, **Google Gemini TTS**, **Xiaomi MiMo TTS**, **ElevenLabs TTS**, **Chatterbox TTS** tự host, **Fish Audio TTS** và chế độ không giọng nói.

Chọn nhà cung cấp và giọng trong WebUI, rồi làm theo hướng dẫn trên màn hình cho các credential cần thiết. Edge TTS không cần API key; [Azure TTS V2](https://portal.azure.com/) và các nhà cung cấp cloud khác cần credential từ nền tảng tương ứng. Xem các giọng Edge TTS có sẵn trong [danh sách giọng](./docs/voice-list.txt).

### Tạo phụ đề

Có hai chế độ tạo phụ đề:

- **edge**: Dùng timestamp từ TTS, chạy nhanh không cần GPU và là chế độ mặc định.
- **whisper**: Dùng phiên âm cục bộ `faster-whisper` khi cần timeline phụ đề chính xác hơn. Mô hình được tải ở lần dùng đầu tiên.

Đặt `subtitle_provider` trong `config.toml` để đổi chế độ. Whisper mặc định dùng mô hình `large-v3` khoảng 3 GB. Để dùng mô hình `large-v3-turbo` nhỏ và nhanh hơn, khoảng 1,6 GB:

```toml
[app]
subtitle_provider = "whisper"

[whisper]
model_size = "large-v3-turbo"
```

> Ở lần dùng đầu tiên, Whisper tự tải mô hình từ Hugging Face. Nếu tải tự động thất bại, hãy tải thủ công `whisper-large-v3` từ [Hugging Face](https://huggingface.co/Systran/faster-whisper-large-v3).

Sau khi giải nén mô hình, đặt toàn bộ thư mục vào `.\MoneyPrinterTurbo\models`. Đường dẫn cuối cùng nên là `.\MoneyPrinterTurbo\models\whisper-large-v3`:

```
MoneyPrinterTurbo
  ├─models
  │   └─whisper-large-v3
  │          config.json
  │          model.bin
  │          preprocessor_config.json
  │          tokenizer.json
  │          vocabulary.json
```

### Nhạc nền

Nhạc nền cho video nằm trong thư mục `resource/songs` của dự án.

> Dự án hiện bao gồm một số nhạc mặc định từ video YouTube. Nếu có vấn đề bản quyền, vui lòng xóa chúng.

### Font phụ đề

Font dùng để render phụ đề video nằm trong thư mục `resource/fonts` của dự án; bạn cũng có thể thêm font của riêng mình.

## Câu hỏi thường gặp 🤔

<details>
<summary>RuntimeError: No ffmpeg exe could be found</summary>

Thông thường, ffmpeg sẽ được tự động tải và phát hiện. Tuy nhiên, nếu môi trường của bạn gặp lỗi khi tải tự động, bạn có thể thấy lỗi sau:

```
RuntimeError: No ffmpeg exe could be found.
Install ffmpeg on your system, or set the IMAGEIO_FFMPEG_EXE environment variable.
```

Trong trường hợp này, tải FFmpeg từ [gyan.dev](https://www.gyan.dev/ffmpeg/builds/), giải nén và đặt `ffmpeg_path` tới đường dẫn cài đặt thật.

```toml
[app]
# Please set according to your actual path, note that Windows path separators are \\
ffmpeg_path = "C:\\Users\\harry\\Downloads\\ffmpeg.exe"
```

</details>

<details>
<summary>OSError: [Errno 24] Too many open files</summary>

Lỗi này do giới hạn số lượng tệp mở của hệ thống. Bạn có thể xử lý bằng cách tăng giới hạn này.

Kiểm tra giới hạn hiện tại:

```shell
ulimit -n
```

Nếu quá thấp, có thể tăng lên, ví dụ:

```shell
ulimit -n 10240
```

</details>
